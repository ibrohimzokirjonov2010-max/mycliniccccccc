# Tooth illustrations (FDI 11–48)

Static PNGs served from `/teeth/{kind}/{fdi}.png`.

## Treatment sets (Dizyner Tish)

Each folder has 32 adult teeth:

- `endo/` — endodontics / kanal davolash
- `caries/` — caries
- `implant/`
- `plomba/`
- `shtift/`
- `breket/`
- `metal-keramika/`
- `sirkon/`

## Default / healthy

- `healthy/` — Dizyner untreated laterals (default)

Mapping lives in `src/utils/toothIllustration.js`.
