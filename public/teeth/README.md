# Tooth illustrations (FDI 11–48)

Static PNGs served from `/teeth/{kind}/{fdi}.png`.

## Treatment sets (Dizyner Tish)

Each folder has 32 adult teeth:

- `endo/` — endodontics / kanal davolash
- `caries/` — caries
- `implant/`
- `plomba/`
- `shtift/`
- `breket/`
- `metal-keramika/`
- `sirkon/`
- `protez-syomniy/` — removable denture
- `protez-implant/` — prosthesis on implant
- `protez-babochka/` — butterfly partial
- `missing/` — extracted / Yo‘q / edentulous

## Default / healthy

- `healthy/` — user sog‘lom-tishlar set (transparent PNGs, 512×512, FDI 11–48). Tooth 44 is a horizontal mirror of 34 (source upload had no 44).

Mapping lives in `src/utils/toothIllustration.js`.
